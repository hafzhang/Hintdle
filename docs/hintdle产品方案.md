# hintdle 产品方案 —— Poople 词梯答案与解题工具站

> 版本：2026-11-22 · 域名：**hintdle.com**（rung＝梯级 + dle＝每日猜词游戏后缀，7 字母，本轮实测可注册）
> 一句话定位：**给 Poople 玩家的一屏式答案 + 分级提示 + 任意词求解工具站**。不做游戏本体，只做答案、提示和工具。

---

## 0. 三条红线（决定站能不能活）

1. **不碰品牌词**：域名、站名、页面标题里不出现 poople / krillion（poopleanswer.com、pooplesolver.com 已被竞品占据且随时可能被商标投诉，站和域名一起丢）。
2. **不做可玩复刻**：游戏本体是对方版权作品；我们只做答案、提示、求解。官方 unlimited 模式是 1,476 道练习题（Easy 786 / Medium 533 / Hard 157）的题库，**不抓这套题库**，只做规则说明 + 随机起始词工具。
3. **数据全部自算**：词图、最短路径、提示全部由自有 BFS 从公开数据算出（已完成并验证），不抓任何竞品内容、不抄任何英文原文。

### 1.3 为什么能赢 poople.org（差异化锚点）

逆向官方 poople.io bundle 已证实（2026-11-22，浏览器实测）：**官方 #464 = JUGS，而 poople.org 标注 #464 = TAXI**——它跑的是自己独立题库，与官方游戏不同步。Rungdle 的数据直接来自官方 bundle 内嵌数据（见 §2），题号、起始词、步数与官方 100% 一致，这是所有竞品都没做到的「真·官方对齐」。

### 2.2 数据来源说明（Methodology 页素材）

官方 poople.io 的 JS bundle 随每次页面访问公开分发，内嵌了完整词图与题目序列；我们下载后用**自有 BFS 独立复算全部距离**并与内嵌数据交叉验证（100% 一致）后采用。词表另与 SOWPODS / ENABLE / dwyl 公开词表交叉比对。全流程零抓取竞品内容、零猜测，任一数字可复现（`build_official_graph.py`）。

### 2.3 有用的图统计（Statistics 页素材）

- 最远 11 步（UMPH / INCH / AUGH）；POOP 一步邻居 11 个（BOOP、COOP、POOF、PROP、POOR、LOOP、POMP、PLOP、GOOP、POOL、HOOP）。
- 距离分布：0 步 ×1、1 步 ×11、2 步 ×56、3 步 ×180、4 步 ×523、5 步 ×879、6 步 ×512、7 步 ×129、8 步 ×67、9 步 ×29、10 步 ×8、11 步 ×3。
- 难度分档（对齐官方「Medium, 5 steps」口径）：1–3 步 Easy / 4–5 步 Medium / 6 步以上 Hard。

|---|---|---|---|

### 3.2 长尾页规则（本站最大的量来自这里）

- **URL 用起始词做键**（`/from/rise/`），**绝不用官方关卡号**——官方题库编号与自有词表对不上，挂「Level #372」而内容不符会被判定错误内容。
- 每页模板：`{WORD} to POOP in {N} steps` 作 H1；唯一/全部最短路径；每步的其他候选词及为什么不更短；难度标签；内链到 `/solver/` 与相邻词页（`/from/{word}/` 互链形成网）。
- 搜索意图覆盖：`"{word} to poop"`、`"poop ladder from {word}"`、`"how to get from {word} to poop"` 三种 title 变体轮换。

### 3.3 二期扩展页（主站稳定后再加）

- `/statistics/`（步数分布、极值词——数据现成）、`/patterns/`（哪些词一步到 POOP——11 词现成）、`/strategy/`（手工解题策略长文）、`/data-methodology/`（E-E-A-T）、`/es/`、`/de/`（竞品已验证有搜索量，先预留 hreflang）。

## 4. 差异化：60 秒答案 + 官方对齐

**竞品上限 2 分 07 秒，多数 12–28 秒。Rungdle 的产品目标：**

1. **一屏给完**：首屏 ≤1 秒可见「起始词 → 步数 → 每一行怎么改 → 复制分享」，无需任何交互。
2. **每步讲清为什么**：写明每一步的其他候选词为什么不更短（BFS 前驱数据天然支持）——这是停留时间 >60 秒的关键内容。
3. **提示是主产品**：四层 spoiler-safe 提示（域名基因），折叠逐级展开，不剧透。
4. **题号真对齐官方**：竞品 poople.org 题号错位（§1.3），我们直接来自官方 bundle。

## 5. 技术方案

| 层 | 选型 | 说明 |
|---|---|---|
| 站点 | **Astro 静态导出** | 约 2,400+ 长尾页 + 8 核心页，构建期全部生成；数据构建与页面构建分离 |
| 部署 | **Cloudflare Pages** | 免费、全球 CDN、每日重建自动部署 |
| 数据 | 构建期 JSON | 词图 CSV / daily JSON 是唯一数据源，前端纯查表，不上传用户输入、无后端 |
| 性能 | 单页内联 CSS、零 JS 优先 | 手机首屏 1 秒内可见答案；solver 页字典按需加载 |
| SEO | sitemap + canonical + BreadcrumbList/WebApplication/FAQPage 三件套 | 每工具页正文 ≥400 字原创；长文页 ≥6,000 字符 |

**每日流水线（16:10，已有调度）**：`fetch_today.py` 下载官方 bundle → 校验（BFS 距离必须与内嵌数据 100% 一致，不一致即失败不写数据）→ 生成 `data/daily/YYYY-MM-DD.json` → 触发站点重建部署 → 健康检查（题号/起始词/步数断言）。历史日期页生成一次后永不重复生成。

**降级铁律**：任一环节失败不写任何数据，页面显示「今日题目更新中」，昨日归档保持可访问。**错数据比不更新更伤**——题号错一次，信任就没了。
